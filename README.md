# 💻 Hiren Siyodia — Developer Portfolio

A modern, interactive **personal developer portfolio website** built with **React.js, Tailwind CSS, Framer Motion, and React Icons**.

This portfolio showcases my **professional experience, education, technical skills, projects, and frontend development journey** through a responsive and visually focused user interface.

---

## ✨ Features

* 🏠 Interactive hero/home section
* 👨‍💻 Personal introduction and developer profile
* 🎓 Education section
* 💼 Professional experience section
* 🚀 Projects showcase
* 🛠️ Technical skills section
* 📄 Resume/CV access
* 📬 Contact section
* 🧭 Smooth navigation between portfolio sections
* 📱 Responsive user interface
* ✨ Framer Motion animations and transitions
* 🎨 Modern dark-themed UI
* 🌌 Animated background effects
* 🖼️ Project image previews
* 🔗 Social media and project links
* 📜 Reusable React components
* ⚡ Fast development and production build using Vite

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/HirenSiyodia/Portfolio.git
```

### 2. Navigate to the project

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will start using the Vite development server.

---

## 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
